# thermos harness adapter

Generated by pstack-portable from thermos `__VERSION__` (cursor/plugins
`__SHA__`). Do not edit; re-run sync.

Thermos's skills were written for Cursor. Read their Cursor terms through this
table for the harness you are running in. Everything else in a skill applies
unchanged.

**Project instructions win.** Where `AGENTS.md`, `CLAUDE.md` or a project
document forbids or gates an action, follow the project and say which gate
stopped you.

**Loading a thermos skill.** Thermos skills set `disable-model-invocation`, so
Claude Code won't load them for a model. When a subagent is told to "load the
`<skill>` skill", it reads `.agents/skills/<skill>/SKILL.md` directly, in every
harness.

**Models.** Thermos names no models. Every subagent runs on your own model.
