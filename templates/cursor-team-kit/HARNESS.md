# cursor-team-kit harness adapter

Generated by pstack-portable from cursor-team-kit `__VERSION__` (cursor/plugins
`__SHA__`). Do not edit; re-run sync.

cursor-team-kit's skills were written for Cursor. Read their Cursor terms
through this table for the harness you are running in. Everything else in a
skill applies unchanged.

**Project instructions win.** Where `AGENTS.md`, `CLAUDE.md` or a project
document forbids or gates an action a skill takes, such as pushing or opening a
PR, follow the project and say which gate stopped you.

**Not included.** `thermo-nuclear-code-quality-review` and its agent come from
Thermos (`--plugin thermos`), which ships the same rubric.

**Rules.** The kit's Cursor rules are in `.agents/cursor-team-kit/RULES.md`.
They apply only where the project's `AGENTS.md` or `CLAUDE.md` points to that
file.
